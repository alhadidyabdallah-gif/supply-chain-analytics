# 📦 Supply Chain & Inventory Analytics Dashboard

## 📊 Project Overview
An end-to-end supply chain analytics project analyzing **200,000+ inventory, shipment, and sales records** for a company operating 10 warehouses across Saudi Arabia.

## 🎯 Business Problem
- No visibility into supplier performance and delivery delays
- Difficulty identifying low-stock products and reordering needs
- Inefficient inventory management across warehouses
- Lack of data-driven insights for cost optimization

## 🛠️ Tools & Technologies
- **MySQL:** 7 interconnected tables (Star Schema)
- **SQL:** Advanced queries (Inventory Turnover, ABC Analysis, Supplier Performance, Window Functions)
- **Power BI:** DAX, Waterfall Chart, Drill-through, Forecasting, Custom Tooltips
- **Data Storytelling:** Strategic recommendations for supply chain optimization
